These files are base64-encoded copies of the official Chromium cursor resources:

- https://chromium.googlesource.com/chromium/src/+/main/ui/resources/cursors/hand_grab.cur
- https://chromium.googlesource.com/chromium/src/+/main/ui/resources/cursors/hand_grabbing.cur
- https://chromium.googlesource.com/chromium/src/+/refs/heads/main/ui/resources/cursors/pan_middle_vertical.cur
- https://chromium.googlesource.com/chromium/src/+/refs/heads/main/ui/resources/cursors/pan_north.cur
- https://chromium.googlesource.com/chromium/src/+/refs/heads/main/ui/resources/cursors/pan_south.cur

They are used by the Windows drag and browser autoscroll cursor bridges and
decoded at runtime from the embedded source. Chromium source files are
distributed under the BSD 3-Clause license. See
https://chromium.googlesource.com/chromium/src/+/refs/heads/main/LICENSE.
